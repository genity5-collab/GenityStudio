# RetroStudio Publisher Source

Use **`retrostudio.html`** as the complete self-contained RetroStudio application source. Copy the full contents of that one file into the publisher whenever you want to release the current GitHub version.

The file includes the OAuth blank-screen safeguards, restored app navigation, the enhanced model selector, visual credit indicators, compact encoded-script cards, and the Model → Script → Encode execution feedback.

> Do not copy the service-role key into this file. The client uses only the publishable Supabase key.
